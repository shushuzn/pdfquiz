例0-1 蒸发器物料衡算 教材 P4
某一连续操作的蒸发器将含 NaOH 为 xF（质量分数）的稀溶液蒸发浓缩到质量分数为 xW。该蒸发器每小时的进料量为 F 千克。试求每小时所得浓碱液量 W 及水分蒸发量 V 各为多少千克。
附图 图0-2
解
（1）画出过程示意图，圈出衡算范围，标出各物理量，如图 0-2 所示。 （2）过程为定态，取 1 h 为衡算基准。 总物料衡算：F = V + W 溶质衡算：F xF = W xW 两式联立解得： W = (xF/xW)F V = (1 − xF/xW)F

例1-1 离心泵进出口压力 教材 P9
一台操作中的离心泵，进口真空表及出口压力表的读数分别为 0.02 MPa 和 0.11 MPa。试求：(1)泵进口与出口的绝对压力(kPa)；(2)二者之间的压力差。设当地的大气压力为 101.3 kPa。
解
（1）进口真空表读数即为真空度： p1 = 101.3 − 0.02×103 = 81.3 kPa 出口压力表读数即为表压： p2 = 101.3 + 0.11×103 = 211.3 kPa （2）两截面压力差： p2 − p1 = 211.3 − 81.3 = 130 kPa 或直接用表压及真空度计算： p2 − p1 = 0.11×103 − (−0.02×103) = 130 kPa
答案p1 = 81.3 kPa，p2 = 211.3 kPa，Δp = 130 kPa

例7-6 理想干燥器空气用量 教材 P345
用气流干燥器干燥某物料，生产能力为 1000kg/h，物料的含水量由 12% 降至 3%。操作压力为 101.3kPa，新鲜空气温度为 20°C、湿度为 0.008kg 水汽/kg 干气，经预热器后温度为 130°C。已知干燥器为理想干燥器，试求：（1）当干燥器空气出口温度为 40°C 时，绝干空气用量及预热器中的加热量；（2）若空气离开干燥器后，因在管道及旋风分离器中散热而使温度下降了 10°C，判断是否会发生产品返潮现象。
解
（1）绝干物料量： GC = G2(1 − w2) = 1000 × (1 − 0.03) = 970kg/h 物料的干基含水量： X1 = w1/(1 − w1) = 0.12/(1 − 0.12) = 0.136 kg 水/kg 干料 X2 = w2/(1 − w2) = 0.03/(1 − 0.03) = 0.0309 kg 水/kg 干料 水分汽化量： W = GC(X1 − X2) = 970 × (0.136 − 0.0309) = 101.95kg/h 因是理想干燥器，空气经历等焓变化过程，即 I1 = I2： (1.01 + 1.88H1)t1 + 2492H1 = (1.01 + 1.88H2)t2 + 2492H2 (1.01 + 1.88 × 0.008) × 130 + 2492 × 0.008 = (1.01 + 1.88H2) × 40 + 2492H2 解得空气出口湿度 H2 = 0.0439 kg 水汽/kg 干气 故绝干空气用量： L = W/(H2 − H1) = 101.95/(0.0439 − 0.008) = 2839.8 kg 干气/h 预热器中加热量： QP = LcH0(t1 − t0) = (2839.8/3600) × (1.01 + 1.88 × 0.008) × (130 − 20) = 88.94kW （2）当干燥器空气出口温度为 40°C 时，假设没有水析出，则其中的水汽分压： pv = pH2/(0.622 + H2) = 101.3 × 0.0439/(0.622 + 0.0439) = 6.68kPa 空气经管道及旋风分离器后温度降至 30°C，该温度下水的饱和蒸气压 ps = 4.25kPa，ps < pv，即空气温度已低于露点温度，必有水分析出，干燥产品将返潮，故干燥器空气出口温度不能过低。
答案L = 2839.8kg 干气/h；QP = 88.94kW；温度降至 30°C 时 ps = 4.25kPa < pv = 6.68kPa，会发生产品返潮
例7-7 恒速干燥速率与干燥时间 教材 P350
现将某固体颗粒物料平铺于盘中干燥。常压下将温度为 20°C、湿度为 0.01kg 水汽/kg 干气的空气预热至 70°C 后送入干燥器，空气以 6m/s 的流速平行流过物料表面。已知单位干燥面积的绝干物料量 GC/A = 23.5kg/m2，物料的临界含水量 XC = 0.21kg 水/kg 干料。试求：（1）恒速干燥阶段的干燥速率；（2）物料含水量从 X1 = 0.45kg 水/kg 干料下降到 X2 = 0.24kg 水/kg 干料所需的干燥时间。
解
（1）湿空气 t = 70°C、H = 0.01kg 水汽/kg 干气，由湿度图查得湿球温度 tw = 30°C；由附录 5 查得 30°C 时水的汽化相变焓 rW = 2424kJ/kg。 干燥器内湿空气的比体积，由式（7-6）： vH = (0.773 + 1.244H) × (273 + t)/273 = (0.773 + 1.244 × 0.01) × (273 + 70)/273 = 0.987 m3/kg 干气 则湿空气的密度： ρ = (1 + H)/vH = (1 + 0.01)/0.987 = 1.023kg/m3 湿空气的质量流速： G = uρ = 6 × 1.023 = 6.14 kg/(m2·s) 空气平行流过物料表面，由式（7-42）计算对流传热系数： α = 14.3G0.8 = 14.3 × 6.140.8 = 61.1 W/(m2·°C) 则恒速干燥阶段的干燥速率： UC = (α/rW)(t − tw) = 61.1/(2424 × 1000) × (70 − 30) = 1.008 × 10-3 kg/(m2·s) （2）因 X2 > XC，故由 X1 = 0.45kg 水/kg 干料降至 X2 = 0.24kg 水/kg 干料仅为恒速干燥阶段，干燥时间： τ1 = GC/(AUC)(X1 − X2) = 23.5/(1.008 × 10-3) × (0.45 − 0.24) = 4896s = 1.36h
答案UC = 1.008 × 10-3 kg/(m2·s)；τ = 4896s（1.36h）
