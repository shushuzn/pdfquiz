# 《化工原理》题库编写规范

你要为《化工原理》（第四版，杨祖荣主编，化学工业出版社）编写期末题库草稿。
教材 PDF 已 OCR 成分章语料，你只能依据语料出题，不许凭记忆补充教材以外的内容。

## 输入与输出

- 语料：`/data/pdfquiz/corpus_hgyl/chNN.md`，`### p123` 是印刷页码标记，正文按行排列。
- 输出：`/data/pdfquiz/papers_hgyl/chNN.json`，UTF-8，JSON，2 空格缩进。
- 参考样例：`/data/pdfquiz/papers_hgyl/ch00.json`（已通过全部检查，照它的风格写）。

## 存储格式

```json
{
  "schema": 2,
  "chapter": "第1章 流体流动与输送机械",
  "questions": [
    {
      "id": "ch01-single-001",
      "type": "single",
      "question": "题干",
      "options": ["选项 A", "选项 B", "选项 C", "选项 D"],
      "answer": "A",
      "explanation": "为什么对、错项错在哪，至少 30 字",
      "evidence": "教材原句，逐字复制",
      "ref": "P23",
      "difficulty": "medium",
      "bloom": "理解"
    }
  ]
}
```

- `type`：`single` 单选、`multiple` 多选、`truefalse` 判断、`fill` 填空、`short` 简答、`term` 术语。
- `id`：`<章>-<题型>-<三位序号>`，如 `ch03-multiple-002`；同章同题型内不重复。
- `answer`：单选 `"B"`；多选 `"AC"` 或 `["A","C"]`；判断 `"true"` / `"false"`；填空与简答写参考答案文本。
- `term` 题必须带 `"mode": "explain"`，`question` 是术语本身，`answer` 是 2~4 句释义。
- `ref`：`P` + 印刷页码，例如 `P47`，必须与 evidence 所在页一致。
- `difficulty`：`easy` / `medium` / `hard`；`bloom`：`记忆` / `理解` / `应用` / `分析` / `评价` / `创造`。

## 硬性规则（检查器会逐条卡）

1. `evidence` 必须能在本章语料里**逐字**找到（允许标点、空白差异，不允许改字、合句、跳行）。
   最稳的做法：从语料里整句复制，长度 15~200 字。
   语料是扫描 OCR，公式和图表区域常有乱码；只挑读得通的完整句子，读不通就换一句或换考点。
2. `explanation` ≥ 30 字，讲清正确项为什么对、干扰项错在哪；不许照抄 evidence，不许出现「课件」二字，不许重复标点（，，。。）。
3. 题干不许以「课件」「本书」「教材第 X 页」开头；不许考页码、图号、章节编号、作者生平。
4. 单选题必须 4 个选项；多选 4 个选项、答案至少 2 个；干扰项要像真选项，不许「以上都对」「以上都不对」「无法判断」。
5. 上下标一律用 Unicode 或 `<sub>`/`<sup>`：m³、m²、kg·m⁻³、10⁻³、h⁻¹、W·m⁻²·K⁻¹、H₂O。
   写成 m3、m2、10-3、H2O 会被判不合格。
6. 数值只在语料清晰可读时使用；OCR 数字常错，拿不准就不要把数字写进题干或选项。
7. 判断题不要出「原文原句照抄」的送分题，要针对常见误解设问（如把推动力当阻力、把沸点升高当下降）。
8. 全章题目考点要分散：定义、机理、判据、设备结构、操作调节、影响因素、易错点各占一些，
   不要连着五道题都考同一节。

## 自检

```bash
cd /data/pdfquiz && python tools/check_hgyl.py ch01
```

必须看到 `全部合格。`。检查器会逐条打印退回原因，按提示改到通过为止。
不要修改 `corpus_hgyl/` 里的语料，也不要动别人的章节文件。

## 难度与风格

按期末考试的标准出题：题干一句话问清一件事，选项短而具体，解析像老师在讲评。
计算题只考「公式的物理意义、适用条件、参数变化后结果怎么变」，不要求代入具体数值。
