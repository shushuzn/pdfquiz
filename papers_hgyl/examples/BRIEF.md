# 教材例题整理说明

`papers_hgyl/examples/chNN.json` 收录《化工原理》（第四版）正文中的全部例题，
供站点「教材例题精解」页使用。例题不计入题库题数，也不参与模拟卷抽题。

## 数据格式

```json
{
  "schema": 1,
  "chapter": "第1章 流体流动与输送机械",
  "examples": [
    {
      "id": "ch01-ex-001",
      "label": "例1-1",
      "ref": "P9",
      "topic": "离心泵进出口压力",
      "problem": "……",
      "solution": "……",
      "answer": "……",
      "figure": "图1-2",
      "note": ""
    }
  ]
}
```

- `id`：`chNN-ex-001`，三位序号，与例题编号一致。
- `label`：`例1-1`，不带空格。
- `ref`：例题起始的**印刷页码**，写成 `P9`；PDF 页码 = 印刷页码 + 9。
- `topic`：4～12 字的主题，用于卡片标题。
- `problem`：完整题意，包含所有已知数据和单位；依赖附图的，把图中用于计算的数据
  也写进题干，并在末尾注明「（图1-24）」。
- `solution`：按教材解法整理的关键步骤，一行一步，公式单独成行；保留代入过程和
  最终结果，不要只写答案。
- `answer`：最终结果一行。
- `figure`：附图编号，如 `图1-24`；没有就留空字符串。
- `note`：看不清、教材笔误或需要说明的假设；正常留空。

## 写法

- 上下标用 `_{}`、`^{}`，例如 `m^{3}/h`、`10^{-3}`、`x_{F}`；页面会渲染成上下标。
- Greek 字母、乘号、约等号直接用 Unicode：`ρ`、`μ`、`λ`、`×`、`≈`、`°C`。
- 不写 HTML 标签，不写 Markdown 表格；分行用 `\n`。
- 数字必须来自教材原页，读不清就写 `[?]` 并在 `note` 说明，**不要猜数**。
- 例题的解答允许压缩推导，但不能跳掉关键衡算式、关联式和最终数值。
